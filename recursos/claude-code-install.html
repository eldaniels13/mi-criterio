Prereqs

01
Verificar cuenta de Anthropic Req

Claude Code no tiene free tier. Necesitás una de estas opciones activas.

opciones
  Claude Pro       →  $20/mes  (incluido)
  Claude Max       →  $100–200/mes  (más límites)
  API Key          →  pay-per-token  →  console.anthropic.com
02
Instalar Git for Windows Req

Claude Code usa Git Bash internamente para ejecutar comandos, incluso desde PowerShell o CMD. Sin Git falla silenciosamente.

powershell
# Opción A — WinGet (recomendado)
winget install Git.Git

# Opción B — descarga manual
# https://git-scm.com  →  usar configuración default
# asegurarse que "Add Git to PATH" esté marcado (default)
⚠

No correr PowerShell como Administrador para instalar Claude Code. Git sí requiere instalación normal de usuario.

Instalación

03
Instalar Claude Code — Native Installer

El instalador nativo no requiere Node.js. Método recomendado por Anthropic desde 2025. npm está deprecado.

powershell
# Opción A — One-liner PowerShell (recomendado)
powershell -c "irm https://claude.ai/install.ps1 | iex"

# Opción B — WinGet
winget install Anthropic.ClaudeCode

# Verificar instalación
claude --version
ℹ

WinGet no auto-actualiza. Para actualizar manualmente: winget upgrade Anthropic.ClaudeCode

04
Fix PATH si claude no se encuentra

Error típico: claude command not found — el instalador pone el binario en ~\.local\bin que puede no estar en PATH.

powershell
# Agregar al PATH del usuario (session actual)
$env:PATH += ";$env:USERPROFILE\.local\bin"

# Hacerlo permanente via GUI:
# Win+R → sysdm.cpl → Advanced → Environment Variables
# User variables → PATH → Edit → New → agregar:
#   %USERPROFILE%\.local\bin
# Reiniciar terminal

# Si Git Bash no se encuentra, agregar en settings:
# %USERPROFILE%\.claude\settings.json
{ "env": { "CLAUDE_CODE_GIT_BASH_PATH": "C:\\Program Files\\Git\\bin\\bash.exe" } }
05
Autenticar y lanzar

El primer launch abre el navegador para autenticar con tu cuenta Anthropic.

powershell
claude
# Se abre browser → loguear con cuenta Anthropic
# Si el browser no abre: Ctrl+Click en la URL del terminal

# Navegar a un proyecto y usar
cd C:\Users\TuUsuario\mi-proyecto
claude
💡

En Windows, pegar imágenes desde clipboard usa Alt+V, no Ctrl+V. Diferencia conocida respecto a macOS.

Instalación

02
Instalar via Native Installer Recomendado

Método oficial. No requiere Node.js. Auto-actualiza en background. Funciona en cualquier distro 64-bit con glibc.

bash
# Instalación nativa (recomendado)
curl -fsSL https://claude.ai/install.sh | bash

# Recargar shell
source ~/.bashrc   # o ~/.zshrc si usás zsh

# Verificar
claude --version
⚠

Arch usa musl/glibc — el instalador nativo funciona bien en Arch estándar (glibc). Alpine o distros con musl requieren la variante musl del binario.

03
Alternativa: AUR Alternativo

Paquete claude-code disponible en AUR. Útil si querés integración con pacman, pero no auto-actualiza — hay que actualizarlo manualmente.

bash
# Con paru (recomendado)
paru -S claude-code

# Con yay
yay -S claude-code

# Manual (si no tenés AUR helper)
git clone https://aur.archlinux.org/claude-code.git
cd claude-code && makepkg -si

# Actualizar manualmente cuando haya nueva versión
paru -Syu claude-code
ℹ

El paquete AUR a veces tiene lag respecto a la versión oficial. Si necesitás la última versión al instante, usá el native installer del paso 02.

04
Autenticar y lanzar

Primer launch abre browser para auth. Si usás entorno sin GUI, copiar la URL manualmente.

bash
claude
# Se abre browser → loguear con cuenta Anthropic
# Sin GUI: copiar URL y pegar en browser externo
# Ctrl+Click en terminal (mayoría de emuladores)

# Navegar a un proyecto y usar
cd ~/proyectos/mi-app
claude

# Tip: sandbox (seguridad mejorada) requiere bubblewrap
sudo pacman -S bubblewrap socat
# Claude Code detecta y activa sandbox automáticamente
💡

Las actualizaciones del native installer son automáticas en background. Revisan en cada startup. Si usaste AUR previamente y querés migrar: curl -fsSL https://claude.ai/install.sh | bash y luego paru -R claude-code.
