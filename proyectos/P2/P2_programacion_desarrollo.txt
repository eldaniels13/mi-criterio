  INSTRUCCIONES PARA CLAUDE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  · Prefiere ejemplos ejecutables sobre explicaciones abstractas.
  · Ante errores: diagnosticar antes de solucionar.
  · Ante preguntas de arquitectura: preguntar primero ¿ya tienes
    algo escrito? y ¿cuál es la restricción principal?
  · El nesting engine es un proyecto productivo, no académico.
    Las decisiones de diseño deben optimizar para: corrección
    geométrica > velocidad > mantenibilidad.
  · Excel avanzado es un subproyecto compartido con Finanzas:
    el objetivo es dominar fórmulas, macros, gráficas, filtros
    y análisis predictivo para finanzas personales y trabajo.
  · MATLAB: referencia válida para entender concepto, pero
    proponer implementación en Python o C# siempre.
  · Certificaciones Python exploradas: PCEP, freeCodeCamp,
    HackerRank, Codewars, DataCamp. Objetivo: portfolio +
    certificación internacional para mercado laboral.
