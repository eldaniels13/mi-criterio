  1. ntfsresize --size 300G → redujo NTFS interno a 300G ✓

  ntfsresize + cfdisk resize en una sola sesión atómica,
  sin correr ntfsfix entre operaciones.

APRENDIZAJES TÉCNICOS DE ESTA SESIÓN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  BIOS/AHCI:
  - Dell Latitude 5400 en modo RAID oculta nvme0n1 a Linux
  - Cambiar RAID→AHCI requiere preparar Windows primero con bcdedit safeboot
  - Sin preparación: Windows entra en BSOD al cambiar modo

  Particionado NTFS:
  - ntfsresize: modifica el filesystem interno (datos)
  - cfdisk: modifica la tabla de particiones (metadata)
  - DEBEN ejecutarse juntos o en secuencia inmediata
  - ntfsfix NUNCA correr entre operaciones de resize
  - GParted hace ambas operaciones atómicamente → más seguro para redimensionar
  - dd graba ISOs bit a bit pero Windows ISOs necesitan estructura UEFI especial
  - woeusb/Rufus son las herramientas correctas para grabar ISOs de Windows

  Estructura NTFS:
  - MFT (Master File Table): índice de todos los archivos
  - $MFTMirr: copia espejo del MFT para recuperación
  - Un MFT corrupto no implica pérdida de datos físicos
  - chkdsk no puede operar si el MFT está demasiado dañado
  - La analogía: biblioteca intacta, catálogo quemado

  Live environments:
  - Arch live tmpfs tiene espacio limitado (~1GB), no instalar paquetes grandes
  - PowerShell no disponible en WinRE
  - GRUB loopback puede arrancar ISOs pero Windows ISOs requieren estructura específica
  - SupportAssist de Dell es recuperación de último recurso sin USB externo
  - partprobe fuerza al kernel a releer tabla de particiones sin reiniciar

  Comandos aprendidos:
  - ntfsfix -d [dispositivo] → limpia flag de chkdsk pendiente
  - ntfsresize --info [dispositivo] → muestra tamaño real del filesystem
  - ntfsresize --size XG [dispositivo] → redimensiona filesystem
  - partprobe [dispositivo] → recarga tabla de particiones
  - testdisk [dispositivo] → recuperación de particiones y filesystems
  - photorec [dispositivo] → recuperación de archivos por firma binaria
  - dd if=[iso] of=[dispositivo] bs=4M status=progress → graba imagen
  - bcdboot C:\Windows /s Z: /f UEFI → reconstruye BCD de arranque Windows
  - iwctl → gestor WiFi en live de Arch
  - lsblk -f → ver discos con filesystem y UUID
  - cfdisk /dev/[disco] → particionado TUI interactivo
