CONCEPTOS APRENDIDOS EN ESTA SESIÓN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  · nvm (Node Version Manager) — capa intermedia para gestionar versiones
    de Node sin tocar el sistema. Todo vive en ~/.nvm/, sin sudo,
    múltiples versiones coexistiendo. LTS = Long Term Support = estable.

  · ~/.zshrc — script que zsh ejecuta al abrir cada terminal. Controla
    PATH, plugins, prompt y comportamiento del shell. source ~/.zshrc
    recarga sin cerrar la terminal.

  · bindkey en zsh — mecanismo para mapear secuencias de escape de la
    terminal a acciones del shell. Las terminales envían códigos como
    ^[[1;5D cuando presionas Ctrl+←; bindkey le dice a zsh qué hacer.

  · Capas de selección en terminal — zsh controla el movimiento del cursor
    dentro de la línea de comandos; el emulador de terminal (cosmic-term)
    controla el resaltado visual. Son independientes.

  · GTK — toolkit gráfico del ecosistema GNOME/Linux. Aplicaciones GTK4
    (como Geary) se integran visualmente con COSMIC mejor que apps con
    su propio sistema visual (como Thunderbird).

  · PGP/GPG — criptografía de llave pública para email. Llave pública
    la comparten todos; llave privada nunca sale de tu máquina. Ni el
    servidor de correo puede leer el contenido cifrado.

  · MUA/MTA/MDA — tres capas del correo: interfaz (Thunderbird), envío
    (SMTP), recepción/almacenamiento (IMAP). En clientes modernos están
    integradas; en setups avanzados se separan para control total.

  · Ollama — servidor HTTP local en puerto 11434 que gestiona modelos LLM.
    Los modelos son archivos en ~/.ollama/models/. Solo uno activo en RAM
    a la vez. Complementa Claude Code (offline/privado vs. razonamiento
    complejo que justifica conexión a Anthropic).

  · Docker — contenedores: paquetes autocontenidos con aplicación + entorno
    completo. Resuelve "en mi máquina funciona". Definido como código en
    Dockerfile, reproducible en cualquier máquina.

  · LC_TIME / locale — sistema de configuración regional en Linux. LANG
    define el idioma base; LC_* individuales sobreescriben aspectos
    específicos. LC_TIME=es_MX.UTF-8 da formato DD/MM/YYYY y lunes=inicio.

  · global.json en .NET — archivo de configuración que especifica qué
    versión de SDK usar. En home (~/.dotnet/global.json) define el default
    global; en cada proyecto tiene precedencia sobre el global.

  · LazyVim — neovim preconfigurado con lazy.nvim como plugin manager.
    31 plugins instalados automáticamente en primera ejecución: LSP,
    treesitter, git, autocompletado, navegación de archivos y más.

  · Nerd Fonts — fuentes tipográficas con miles de íconos adicionales
    (lenguajes, git, archivos). Necesarias para que LazyVim y starship
    muestren íconos en lugar de cuadros vacíos □.
