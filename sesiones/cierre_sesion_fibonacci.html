Paso 0 — antes de tocar el disco ▶
CRÍTICO: sin backup no hay dual boot. Si el particionado falla, pierdes Windows.
Opciones de backup (elige una): Opción A: Macrium Reflect Free (Windows) → imagen completa del disco Opción B: OneDrive + exportar configuraciones importantes Opción C: Disco externo → documentos, proyectos, configuraciones Lo mínimo a respaldar: documentos, proyectos de código (nesting engine), configuraciones de AutoCAD, credenciales.
Paso 1 — preparar espacio en disco ▶
Desde Windows, reducir la partición para hacer espacio para Arch. Win + X → Administración de discos Click derecho en C: → Reducir volumen Reducir ~60-80GB para Arch NO crear nueva partición — dejar el espacio sin asignar
Paso 2 — arrancar ISO de Arch ▶
Descargar ISO: archlinux.org/download Windows: usar Balena Etcher o Rufus para grabar el USB BIOS Dell: F2 o F12 al arrancar → seleccionar USB Tu Dell Latitude 5400 tiene UEFI — proceso idéntico al que hicimos en VM.
Paso 3 — particionado (el más delicado) ▶
No tocar las particiones de Windows. Solo usar el espacio sin asignar.
lsblk # verificar discos cfdisk /dev/nvme0n1 # o /dev/sda según el Dell Crear en el espacio libre: → 512MB EFI (usar la misma partición EFI de Windows) → 4GB swap → resto ext4 (raíz /)
Paso 4 — instalación Arch ▶
mount /dev/nvme0n1p3 /mnt mount /dev/nvme0n1p1 /mnt/boot pacstrap -K /mnt base linux linux-firmware genfstab -U /mnt >> /mnt/etc/fstab arch-chroot /mnt # Dentro del chroot: pacman -S grub efibootmgr networkmanager sudo grub-install --target=x86_64-efi --efi-directory=/boot --bootloader-id=GRUB grub-mkconfig -o /boot/grub/grub.cfg # detectará Windows automáticamente
Paso 5 — instalar COSMIC ▶
sudo pacman -S cosmic-session # o desde AUR: yay -S cosmic-session sudo systemctl enable cosmic-greeter LazyVim instalar aquí con buena conexión.

Errores encontrados y resoluciones
linux-firmware typo → reinstalar sin -K
Espacio insuficiente → /mnt no estaba montada correctamente
GRUB i386-pc en VM UEFI → reinstalar con --target=x86_64-efi
fstab duplicado → genfstab corrido dos veces con >>
db.lck huérfano → sudo rm /var/lib/pacman/db.lck
yay falla Go DNS → GOPROXY=direct + deshabilitar IPv6
picom incompatible con VirtualBox GPU → deferido a hardware real
LazyVim clone timeout → requiere mejor conexión
