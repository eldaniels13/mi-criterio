CONCEPTOS APRENDIDOS EN ESTA SESIÓN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  · Claude Code hook events son PascalCase, no camelCase:
    SessionStart, PreToolUse, PostToolUse, UserPromptSubmit,
    Stop, PreCompact, etc. El warning "Unknown hook event" indica
    camelCase o typo, no problema semántico.

  · Schema real de Claude Code .claude/settings.json:
    permissions.{allow,deny,ask} con formato de reglas
    Bash(cmd), Read(path), Edit(path), WebFetch(domain).
    Soporta $schema para validación inline en editores.

  · Jerarquía de settings (de más baja a más alta prioridad):
    managed-settings.json → ~/.claude/settings.json →
    .claude/settings.json → .claude/settings.local.json → CLI flags.

  · claude-mem arquitectura:
    · Worker corre como HTTP server local (37777)
    · Observations en SQLite con FTS5 para búsqueda
    · Chroma local para embeddings vectoriales
    · Triggers ai/ad/au mantienen índice FTS automáticamente
    · Provider "claude" usa tu sesión CLI → data viaja a Anthropic
      API durante generación de resúmenes (arquitectura explícita)

  · Auditoría de seguridad sobre SQLite:
    · .schema tabla       → ver columnas reales antes de query
    · FTS5 MATCH          → búsqueda full-text rápida
    · LIKE multi-columna  → para strings sin tokenización clara
    · UPDATE + REPLACE()  → redacción quirúrgica preservando fila
    · BEGIN/COMMIT        → transacción para cambios destructivos
    · SELECT changes()    → verificar cuántas filas se tocaron

  · Marco de calibración de riesgo PII:
    "Información presente" ≠ "Información sensible".
    Lo que diseñaste para ser público no es filtración aunque
    aparezca en logs/DBs. Lo sensible es lo que permite
    suplantación, daño directo, o acceso no autorizado.

  · Heredoc en zsh con EOF:
    cat > archivo << 'EOF'  ← las comillas evitan expansión
    ...contenido...          de variables del shell dentro
    EOF                      del heredoc. Sin comillas, $VAR
                             se expande antes de escribir.
