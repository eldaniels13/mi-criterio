  · sudo pierde el display de Wayland → usar --text para CLI
    o lanzar veracrypt sin sudo para GUI (udisks2 maneja permisos)
  · Flujo correcto: veracrypt --text [archivo.vc] [mountpoint]
  · "target is busy" → algún proceso tiene abierto un archivo adentro
    → lsof [ruta] para identificar → pkill [nombre] para matar
  · Orden de desmontaje: primero VeraCrypt, después el Kingston

CONCEPTOS APRENDIDOS EN ESTA SESIÓN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  · .bashrc / .zshrc — scripts de configuración que se ejecutan al
    abrir terminal. source ~/.bashrc recarga sin cerrar la terminal.
  · PIM en VeraCrypt — Personal Iterations Multiplier, multiplica
    las iteraciones de derivación de clave. Si no configuraste uno
    al crear el contenedor, siempre es Enter (valor 0 = default).
  · Keyfile en VeraCrypt — archivo adicional como segundo factor.
    Si no configuraste uno, siempre es Enter.
  · nvm vs npm global vs pacman para Node — nvm es la práctica
    profesional: instala Node completamente en ~/.nvm/, sin sudo,
    sin tocar /usr/lib, con soporte para múltiples versiones.
  · Node LTS vs bleeding edge — LTS (Long Term Support) es estable
    y con soporte extendido. pacman instaló v25.9.0 (bleeding edge),
    nvm instaló v24.14.1 (LTS). Para producción siempre LTS.
  · XDG Base Directory — estándar de Linux para carpetas de usuario.
    xdg-user-dirs-update crea Documentos, Descargas, Imágenes, etc.
    en el idioma del sistema.
  · udisks2 — daemon que permite a usuarios normales montar/desmontar
    dispositivos USB sin sudo. Equivalente al "quitar hardware con
    seguridad" de Windows. Con exfatprogs instalado, Kingston NV3
    aparece automáticamente en el explorador al conectar.
  · lsof — "list open files", muestra qué proceso tiene abierto
    un archivo o directorio. Clave para diagnosticar "target is busy".
  · pkill — mata procesos por nombre. pkill soffice mata LibreOffice
    aunque no haya ventana visible (proceso quickstarter en background).
  · Capas del shell — shell (zsh/bash/fish) es el intérprete de
    comandos. Prompt (starship/p10k) es solo lo que se muestra en
    pantalla. Son independientes y combinables libremente.
  · power-profiles-daemon vs system76-power — system76-power es para
    hardware System76 exclusivamente. Para Dell usar power-profiles-daemon
    que es el estándar freedesktop compatible con cualquier hardware.
