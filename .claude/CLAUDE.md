# mi-criterio project CLAUDE.md

This file extends the global `~/.claude/CLAUDE.md` with project-specific instructions for the mi-criterio knowledge architecture repository.

## Quick context activation

Use slash commands to load domain-specific context:

- `/p1-cad` — CNC, CAD, manufacturing context (P1)
- `/p2-code` — Programming & development context (P2)
- `/p3-energy` — Energy, sustainability, renewables context (P3)
- `/p6-future` — Career, decision-making, future planning context (P6)

## What this repo is

A personal knowledge architecture — not a software project. Contains:
- Master profile (`perfil_maestro_eldaniels_v2.txt`)
- Eight thematic lenses (P1–P8) for organizing interests and expertise
- Crosstalk framework for multi-lens problem analysis
- Session logs and decision records

## Key files

- `perfil_maestro_eldaniels_v2.txt` — Always-current master context
- `proyectos/P*/` — Individual project lenses (use `/p1`, `/p2`, etc. to load)
- `ToDo_global_eldaniels.txt` — Master task list
- `cronograma_intereses.md` — Timeline of skill evolution (PENDIENTE)

## Guidance for this work

When working in mi-criterio:

- Commit when updating any major document (career change, new tool, new interest)
- Use commit style: `update P3: [what changed]` or `perfil: [status]`
- Cross-reference related lenses when a task touches multiple domains
- When suggesting a commit, use `/ commit` skill to verify the approach first

For more, see the global `~/.claude/CLAUDE.md` and CLAUDE.md in the project root.
